2 기술 방식 결정
왜 Electron + BrowserView인가?
방식설명적합성
Playwright / Puppeteer (헤드리스) 백그라운드에서 브라우저 조작, 화면 안 보임 ❌ 불적합
사용자가 대화창 못 봄
Electron + BrowserView 실제 웹사이트를 앱 창 안에 임베드, 사용자도 보임 ✅ 최적
iframe 대부분의 AI 사이트가 iframe 차단 (X-Frame-Options) ❌ 불가

BrowserView란 Electron이 제공하는 기능으로, 실제 크롬 브라우저 창을 앱 안에 붙여넣는 방식입니다. 사용자는 실제 Gemini/Claude/ChatGPT 화면을 보면서, 앱이 뒤에서 자동으로 텍스트를 입력하고 추출합니다.

3 핵심 작동 원리
앱 실행
↓
5개 BrowserView 생성 — 각 AI 사이트 로드
↓
사용자: 각 AI에 수동 로그인 (최초 1회)
↓
사용자: Primary AI 선택 + 질문 입력
↓
앱이 Primary AI 입력창에 자동 타이핑 + 전송
↓
Primary AI 답변 완료 감지 → 텍스트 추출
↓
나머지 4개 AI 입력창에 "답변 + 리뷰 요청" 자동 입력
↓
4개 AI 답변 완료 감지 → Feedback 텍스트 추출
↓
Primary AI에게 "Feedback 종합 + 수정 요청" 자동 입력
↓
최종 수정 답변 완료 → 사용자에게 표시

5 각 AI 사이트별 자동화 방법

앱이 각 사이트에 JavaScript를 주입해서 입력/추출을 수행합니다.

AI사이트자동화 방식

자동화 핵심 동작 예시 (JavaScript)
// 입력창에 텍스트 입력 (각 사이트마다 selector 다름) document.querySelector('div[contenteditable]').innerText = "질문내용"; // 전송 버튼 클릭 document.querySelector('button[data-testid="send-button"]').click(); // 답변 완료 감지: 일정 시간 동안 새 텍스트가 추가되지 않으면 완료로 판단 // → MutationObserver로 DOM 변화 감시 // 최신 답변 텍스트 추출 document.querySelectorAll('.message')[last].innerText;
6 기술적 도전과 해결책
도전해결책
각 AI 사이트 DOM 구조가 다름사이트별 selector 설정 파일로 분리 관리
사이트 UI 업데이트 시 셀렉터 깨짐셀렉터를 앱 외부 JSON 파일로 분리해 수정 용이하게
답변 완료 시점 감지MutationObserver + 텍스트 변화 감지 타이머 + 로딩 스피너 소멸 감지
로그인 필요사용자가 최초 1회 수동 로그인, 이후 세션 유지
일부 사이트 봇 탐지실제 사람처럼 타이핑 딜레이 적용
7 앱 내 프롬프트 템플릿 (자동 생성)
Reviewer AI에게 보내는 메시지
아래는 [Gemini]가 다음 질문에 대해 답변한 내용입니다. 질문: {사용자 질문} [Gemini]의 답변: {Primary AI 답변} 위 답변을 리뷰해주세요: 1. 정확성 (사실 오류가 있는가?) 2. 완전성 (중요한 내용이 빠졌는가?) 3. 명확성 (이해하기 어려운 부분이 있는가?) 4. 개선 제안
Primary AI에게 보내는 최종 수정 요청
당신이 이전에 준 답변에 대해 다른 AI들이 피드백을 주었습니다. [Claude의 피드백]: {feedback1} [ChatGPT의 피드백]: {feedback2} [Perplexity의 피드백]: {feedback3} 각 피드백에 대해: - 수용할 것: (이유 포함) - 거부할 것: (이유 포함) 을 명시한 후, 최종 수정된 답변을 작성해주세요.

9 개발 단계 (Roadmap)
단계내용
1단계Electron 프로젝트 세팅 + 5분할 BrowserView 레이아웃
2단계각 AI 사이트 셀렉터 분석 + 텍스트 입력 / 추출 스크립트
3단계답변 완료 감지 로직 (MutationObserver + 타이머)
4단계리뷰 루프 오케스트레이션 (자동화 흐름 전체)
5단계UI 상태 표시 (진행중 / 완료 / 오류 등)
6단계설정 화면, 히스토리 저장, 패키징 (installer)
10 주의사항
⚠️ 이 방식은 기술적으로 구현 가능하지만, 각 AI 서비스의 이용약관(ToS)상 자동화 스크립트 사용을 제한할 수 있습니다. 개인적 / 실험적 용도로 사용하는 것을 권장합니다.
