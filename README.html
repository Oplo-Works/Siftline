🍎 macOS — Install from DMG

  1. Check your chip: Apple menu → About This Mac → Chip. "Apple M…" → arm64 build; "Intel Core…" → x64 build.
  2. Double-click the .dmg file to mount it.
  3. Drag Siftline into the Applications folder.
  4. Launch from Launchpad or Finder → Applications.
⚠️
macOS Gatekeeper & "Damaged" Error

Because the app is not code-signed, macOS may block it or show an error saying the app is "damaged".

  • Install First: Move the app to the /Applications folder.
  • Open Terminal: Press Cmd + Space and search for Terminal.
  • Run Command: Paste xattr -cr "/Applications/Siftline.app" and press Enter.
  • Enter Password: Type your Mac password (it will be invisible) and press Enter.
  • Launch: Double-click Siftline in your Applications folder.

Still won't open? Right-click → Open → Open.

🪟 Windows — Install from EXE

  1. Download AI-Council-Setup.exe.
  2. Double-click to run the setup wizard.
  3. Launch from the desktop shortcut or Start Menu.
⚠️ Windows SmartScreen: Click "More info" → "Run anyway" if prompted.
📱 Telegram Integration

Remote-control Siftline from your phone

The Electron main process runs a long-poll loop (getUpdates) that listens for Telegram messages — no server, no ngrok, no open ports required. When a message arrives, it's routed to the active Council Chat session exactly as if you typed it on the desktop. AI replies are sent back via sendMessage.

Setup (3 steps)

  1. Create a Telegram bot via @BotFather

    Open Telegram → search @BotFather → send /newbot → follow the prompts. BotFather will give you a bot token like 123456789:AAH…. Copy it.

  2. Find your personal Chat ID

    Option A: Open @userinfobot in Telegram — it instantly replies with your Chat ID (e.g. 987654321).
    Option B: Enable the bot first, send any message, then check the 📊 Logs drawer in Siftline for a line like Telegram: message from chat_id 987654321.

  3. Configure in Siftline

    Click the 📱 Telegram button in the title bar → paste your Bot Token and Chat ID → toggle Enable Telegram Bot ON → click Save & Apply.
    The status bar will show ◉ Telegram when the bot is active.

Supported formats: pdf, doc, docx, xls, xlsx, txt, md, csv, json, html, png, jpg, jpeg, webp, gif, bmp.

Security

  • Bot token stored in an encrypted electron-store file — never in logs, never committed to git.
  • Messages from any Chat ID other than yours are silently rejected (no reply, no log of content).
  • lastUpdateId is persisted so old messages are never replayed after restart.

📎 File Attachment in Council Chat

Click the +Attach button in the input bar to attach files before sending a message.

  • Files are physically uploaded to each AI browser via CDP (Chrome DevTools Protocol).
  • When CDP upload is unavailable, extracted text is included inline in the prompt as fallback.
  • Multiple files supported; each shows as a removable chip.
