AI Council

Manual cross-verification workflow among up to 5 major LLMs using Electron BrowserViews and UI automation.

✦ Gemini ◎ Claude ⊕ ChatGPT ◈ Perplexity ⚡ Grok

Setup & Run

Quick Start

1️⃣ First-time install (when moving to a new PC)
Note: node_modules includes binaries that depend on your OS/CPU environment.
If you moved the project to a different PC, delete it and reinstall. 
# Delete node_modules (PowerShell)
Remove-Item -Recurse -Force node_modules

# Reinstall dependencies
npm install

If you only replaced source files on the same PC, you can run it right away without npm install.
However, if new packages were added to package.json, run npm install once.

2️⃣ AI service login — via 🔑 Accounts panel (recommended)
🔑 Click the key icon in the top-right corner of the title bar at any time.
The Accounts panel opens and shows real-time login status for each of the 5 AIs:

  ● Login — opens a dedicated login window; session is saved automatically
  ● Re-login — re-authenticate an already-logged-in account
  ● Logout — clears the session for that AI only
  ● Logout All — clears all sessions at once

Sessions are persisted in the Electron persist: partition and survive app restarts.

Alternative — standalone login scripts (run outside the app):

google-login.bat       # Gemini (Google account)
claude-login.bat       # Claude.ai (including Google OAuth popup)
chatgpt-login.bat      # ChatGPT
perplexity-login.bat   # Perplexity
grok-login.bat         # Grok (X / Twitter account)
3️⃣ Select which AIs are active

The toolbar has two rows of AI chip buttons:

Primary AI
Choose which AI answers first (generates the initial draft). Always active — cannot be toggled off.
Active
Toggle which AI panels are visible and participate in the workflow. Run with 2, 3, 4, or all 5 AIs simultaneously. Click any chip to show/hide that AI's panel.
4️⃣ Run in dev mode (code changes + hot reload) 
npm start

The Electron window opens automatically.

5️⃣ Build and run (production mode) 
npm run build
npx electron .

The app runs after dist/ and dist-electron/ are created.

6️⃣ Package portable EXE (distribution) 
npm run package

After the build, release/AI-Council-Portable.exe is created. It's a single executable that runs without installation.

7️⃣ Create installer EXE (setup program) 
npm run package:installer

An NSIS-based installer wizard EXE is created in release/.

⚙️ Node.js v18+  ·  npm v9+
Execution Flow

Workflow — Manual 3-Step Control

The workflow is manual — you advance each stage by clicking the action button. This lets you review intermediate results before proceeding.

▶ Start
Sends your query to the Primary AI and waits for its draft answer
▶▶ Next
Primary has answered. Sends the draft to all active Reviewer AIs in parallel
✓ Continue
All reviewers done. Sends feedback back to Primary AI for final revision
1
App loads all selected AI websites in BrowserViews — log in via the 🔑 Accounts panel or standalone login scripts
2
Select Primary AI and configure Active panels (choose 2–5 AIs)
3
Type your question, optionally attach files (PDF / DOCX / XLSX / TXT / MD / CSV), click ▶ Start
4
MutationObserver-based stability detection waits for Primary AI's draft response — button turns amber ▶▶ Next
5
Click ▶▶ Next: review prompt (draft + file context) injected simultaneously into all active Reviewer AIs
6
Wait for all reviewer feedback responses (parallel, with per-AI stability detection) — button turns green ✓ Continue
7
Click ✓ Continue: combined feedback + final revision prompt injected back into Primary AI
8
Final revised answer extracted, parsed into per-file blocks, displayed in collapsible Final Result Panel with individual download buttons
Account Management

Accounts Panel 🔑

Click the 🔑 key icon in the top-right of the title bar at any time — even while the app is running.

ActionWhat it does
LoginOpens a dedicated mini browser window for that AI's login page. Session is saved to the persist: partition automatically on window close.
Re-loginRe-authenticates an already-logged-in account (useful when a session expires).
LogoutClears the session cookies for that specific AI only.
Logout AllLogs out all 5 AIs simultaneously.
Live status: The panel shows a real-time ● / ○ indicator for each AI. Status updates instantly via the onLoginStatusChanged IPC event whenever you log in or out.
Feature

File Attachment

If you attach files with your question, all active AIs analyze the file contents, and you can download the final revised version separated per file.

Supported formatsExtraction methodSaved as
.pdfpdf-parse (text extraction).txt
.docxmammoth (body extraction).docx (regenerated)
.xlsxxlsx (sheets → CSV).xlsx (regenerated)
.txt / .md / .csvRead UTF-8 directlyKeep original extension
How it works: File content is included as text in the Primary AI prompt. Reviewer AIs receive the same file context. The final answer outputs per-file revisions using <<<FILE:filename>>> … <<<END_FILE>>> delimiters and the panel shows a per-file save button.
📎 Attach multiple files at once ⬇ Download each file separately 80,000-character context limit

Maintenance

Selector Maintenance

DOM selectors are defined in electron/selectors.json and inlined at build time.
To override without rebuilding, place a custom selectors.json in the app's userData directory:

Windows: %APPDATA%\ai-council\selectors.json
