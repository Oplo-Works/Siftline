우리 팀은 6개월 안에 B2B SaaS 제품의 가격 정책을 전면 개편하려고 한다.
아래 구조에 맞춰 단계별로 분석해줘. 각 섹션은 반드시 순서대로 답할 것.

1. 현재 상황 요약
   - 월 구독 $49 단일 플랜, 기능 제한 없음
   - 고객의 70%는 5인 이하 소규모 팀
   - 이탈 사유 1위는 "사용량 대비 과금 부담"

2. 검토 중인 세 가지 안
   - A안: 사용량 기반 과금(MAU 구간별)
   - B안: 3단계 티어(Starter / Growth / Enterprise)
   - C안: 기본료 + 초과 사용량 하이브리드

3. 각 안에 대해 다음을 평가해줘
   - 예상 매출 영향 (낙관/기본/비관 3시나리오)
   - 기존 고객 grandfathering 전략
   - 경쟁사 대비 포지셔닝 리스크

4. 추가 제약 조건
   - 결제 시스템 마이그레이션은 이번 분기에 불가
   - 연간 결제 할인율은 20%를 유지해야 함
   - 무료 체험 기간은 14일에서 줄이지 않는다

5. 최종 출력 형식
   - 각 안의 장단점 표
   - 추천안 1개와 그 이유 3가지
   - 실행 로드맵 (주 단위, 6개월)

답변은 한국어로 작성하고, 확신이 낮은 추정치에는 반드시 "(추정)" 표시를 붙여줘.
